# SAR Drone Swarm Simulation (AI Agent Development)

Venture Project (Track V) for Principles of AI-001.
This project demonstrates a Multi-Agent system for Search and Rescue operations using LLM-driven autonomous drones.

## System Architecture
* **Frontend:** Streamlit (Web UI) / Pygame (Desktop UI)
* **Backend:** Python + Blackboard Pattern for shared memory
* **AI Logic:** Claude API (Agentic reasoning)
* **Data Management:** SQLite (Telemetry & LLM Decision logging)
